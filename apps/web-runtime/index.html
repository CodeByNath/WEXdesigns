02

Core rules

The constraints shared by every WEX composition.

  • Small, Default, and Large are the only global tiers.
  • Parents own direct-child allocation, gap, and boundary padding.
  • Every layout participant can shrink with min-width: 0.
  • Semantic roles resolve color; local interfaces do not invent values.
  • Domain behavior stays outside shared presentation.
